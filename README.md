# ENCORE — V3 interactive prototype

A mobile-friendly concept for a personalised live-music discovery platform.

## Prototype features
- One homepage featuring **Just Announced**, **Gigs From Your Artists**, and **Festivals**
- Genre filtering for the Just Announced section
- Artist following and a separate **My Artists** management view
- City selection, search, and event details
- Official ticket and resale options (Tixel/Viagogo) displayed inside event details
- Browser-local demo preferences

## Important
All event listings, announcements, dates, ticket availability, and links are **fictional demo content**. This version has no live concert data, accounts, ticket inventory, or automated notifications. Do not treat the displayed ticket options as verified listings.

## Run
Open `index.html` in a browser or host the repository via GitHub Pages. No build process or API keys required.
